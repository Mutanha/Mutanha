## Repository guide

- [datasets](https://github.com/Mutanha/datasets) is my fork of the [Satellite Image Deep Learning dataset index](https://github.com/satellite-image-deep-learning/datasets). It catalogs satellite and aerial imagery datasets for deep learning and remote sensing.
- [uxplay-windows](https://github.com/Mutanha/uxplay-windows) is my fork of [UXPlay for Windows](https://github.com/leapbtw/uxplay-windows), an AirPlay receiver for Windows. The upstream project publishes [downloads and release notes](https://github.com/leapbtw/uxplay-windows/releases).
